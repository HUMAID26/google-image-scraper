🔍 Google Image Scraper — Flask & Beautiful Soup

A Flask-based web application that dynamically fetches and displays Google Images using Python and Beautiful Soup.

---

📌 Overview

This project demonstrates real-time web scraping by allowing users to search for images through a simple frontend interface. The application processes user queries, extracts image data, and renders the results dynamically on the webpage.

---

✨ Features

- Real-time Google Image scraping
- Flask backend integration
- Dynamic frontend image rendering
- Keyword-based image search
- HTML parsing using Beautiful Soup

---

🛠️ Technologies Used

Category| Technology
Language| Python
Backend| Flask
Scraping| Beautiful Soup 4
HTTP Requests| Requests
Frontend| HTML, CSS

---

⚙️ Workflow

1. User enters a search keyword
2. Flask processes the request
3. Beautiful Soup extracts image data
4. Image URLs are sent to the frontend
5. Results are displayed dynamically

---

🚀 Installation

git clone https://github.com/HUMAID26/google-image-scraper.git

cd google-image-scraper-flask

pip install -r requirements.txt

python app.py

Open in browser:

http://127.0.0.1:5000
